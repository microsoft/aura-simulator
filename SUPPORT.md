# Support

## How to file issues and get help

This project uses GitHub Issues to track bugs and feature requests. Please search the [existing issues](https://github.com/microsoft/aura-simulator/issues) before filing new issues to avoid duplicates. For new issues, file your bug or feature request as a new Issue.

For help and questions about using this project, please open a [Discussion](https://github.com/microsoft/aura-simulator/discussions) or reach out through GitHub Issues.

## Microsoft Support Policy

Support for Aura is limited to the resources listed above. This is a research artifact released under the MIT License; it is not a Microsoft product or service, and no SLA or commercial support is provided. Issues and pull requests are reviewed on a best-effort basis by the maintainers.
